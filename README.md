# VioletBank — Static 3-page Fintech Site

Minimal, modern static site scaffold with smooth animations.

Preview locally:

```bash
cd "fintech-site" && python3 -m http.server 8000
# then open http://localhost:8000
```

Files created:
- `index.html` — Home
- `services.html` — Services
- `about.html` — About
- `css/style.css` — Styles and animations
- `js/main.js` — Reveal and smooth scroll logic
- `assets/logo.svg` — Simple site logo

Customize colors in `css/style.css` using CSS variables at the top.
